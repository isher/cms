QsisCMS 核心功能特性

QsisCMS 是一款轻量、高效、无数据库的自研 SSG 静态内容管理系统，专为博客、文档站、资讯站点、个人官网打造。摒弃传统动态程序的冗余负担，以纯文件静态生成 为核心，兼顾极简运维、极致访问速度与专业 SEO 能力，支持一键 Git 自动部署，开箱即用、自由扩展。

一、无库极简架构，轻量零负担

系统全程不依赖 MySQL、SQLite 等任何数据库，所有文章、配置、分类、标签数据均以文件形式本地存储。架构极简、部署零门槛，全站无动态读写请求，彻底杜绝数据库崩溃、注入攻击、数据丢失等问题。站点迁移、备份、克隆仅需复制文件夹，新手也能轻松运维。

二、SSG 全静态生成，访问极速高效

采用主流静态站点生成方案，后台编辑内容后一键生成纯静态 HTML 页面。相较于 PHP、Java 等动态程序，页面无需后端渲染，浏览器直接加载，访问速度大幅提升，极低服务器负载，高并发场景稳定不卡顿，完美适配各类主机、静态托管平台。

三、智能增量构建，发布高效省时

内置精准增量构建机制，系统自动比对文件缓存与磁盘文件差异，仅重新生成修改、新增的页面，无需全站重复构建。大幅缩短发布耗时，海量文章场景下依旧可以实现秒级更新，告别传统全站重构的低效问题。同时兼容全量强制构建模式，一键重置全站静态资源。

四、Markdown 极简创作，专注内容本身

原生支持 Markdown 语法编辑创作，适配标题、列表、代码块、引用、加粗、斜体等常用格式，支持代码高亮、图文混排。后台编辑器清爽无冗余功能，让创作者专注内容撰写，无需复杂排版操作，同时支持文章批量导入、导出，内容迁移灵活便捷。

五、全套站点生态，自带完整能力

系统内置全站配套资源自动生成能力，无需手动配置开发，开箱即用：

  1. 自动生成 Sitemap 站点地图、RSS 订阅源，适配搜索引擎与订阅场景
  2. 自动生成全站搜索索引文件，支持站内全文搜索功能
  3. 自动生成分类列表页、标签列表页，支持分页展示
  4. 自动生成标准化 404 错误页面、站点链接清单 urls.txt

六、专业 SEO 优化，助力收录排名

深度适配搜索引擎优化规则，内置全套 SEO 能力，助力站点快速收录、稳定排名：

  1. 支持 IndexNow 主动推送，页面更新后自动推送至搜索引擎，大幅提升收录效率
  2. 内置 Canonical 标准化链接标签，规避重复页面权重分散问题
  3. 支持后台可视化编辑 robots.txt，自由管控爬虫抓取规则
  4. 页面元数据独立可控，发布时间、摘要、关键词精准配置

七、一键 Git 自动部署，无缝托管发布

内置成熟 GitHub 同步部署模块，支持增量上传、全量强制上传双模式，后台一键触发全站推送，无缝适配 GitHub Pages 静态托管。内置任务锁机制，防止多并发推送冲突，全程日志可视化输出，每一次发布均可追溯，彻底告别手动上传、手动推送的繁琐操作。

八、灵活模板引擎，自由定制样式

采用内容与模板分离设计，模板文件完全开源可编辑。用户可自由修改页面布局、配色、导航、页脚、首页样式，支持自定义主题模板，无需改动核心程序代码，即可实现站点外观全方位定制，适配个人、企业、文档站等各类场景。

九、完善后台管理，运维便捷可控

配套可视化管理后台，功能全面、操作简洁：

  1. 文章全流程管理：新增、编辑、删除、批量管理、内容预览
  2. 站点全局配置：站点信息、静态地址、托管密钥、推送规则配置
  3. 权限管控：多管理员权限分配，精细化操作权限区分
  4. 操作日志审计：记录每一次发布、配置修改行为，全程可追溯

十、高可扩展设计，适配多元场景

系统源码完全自主可控，无厂商锁定、无加密冗余，支持二次开发。内置跨站同步接口，支持多站点内容互通，适配多语言站点搭建、专题页面拓展、自定义功能开发，可灵活适配个人博客、企业官网、技术文档站、资讯小型站点等各类使用场景。

总结

QsisCMS 以 轻量、稳定、高效、开源、免数据库 为核心优势，兼顾新手易用性与开发者拓展性，一站式解决静态站点搭建、创作、优化、部署全流程需求，是极简建站、轻量化内容运营的优质解决方案。
