FAQ

常见问题

QsisCms 需要线上 PHP 环境运行吗？
不需要。PHP 仅用于本地生成静态页面，生成完毕输出纯 HTML，线上服务器只需要支持静态文件即可。
可以用来做产品官网吗？
完全可以，支持自定义首页、导航菜单、文章文档系统，本套主题就是产品官网模板。
是否支持自定义主题？
支持，PHP站点主题由 PHP 模板 + CSS 组成，静态站点由 SSG 静态主题 + CSS 组成开发者可以直接修改或者新建自己的主题。
支持什么格式写文章？
在线编辑以及全面兼容Markdown文件，支持元数据配置标题、标签、时间、封面图、摘要。
