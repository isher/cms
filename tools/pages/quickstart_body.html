Quick Start

快速开始：十分钟从零跑到能发文

QScms 是文件存储，不需要数据库。只要有一个能跑 PHP 的空间，拷进去就能用；跑完这一步，站点即可发文、可一键生成静态站。

1. 环境准备

项目要求
PHP8.x（8.2 实测最稳），语法按 PHP 8 对待
扩展mbstring、gd、curl、bcmath、exif、openssl、zip / ZipArchive（ftp 可选，用于 FTP 备份）
Web 服务器Apache（mod_rewrite + AllowOverride All）或 Nginx + PHP-FPM
数据库不需要
可写目录配置与数据目录、上传目录、后台临时与日志目录、备份与静态输出目录

目录权限按「目录 755、文件 644」设置，属主为 Web 运行用户即可，不要整站 chmod 777。仓库 scripts/ 下有 Linux 与 Windows 的一键权限修复脚本，会自动探测站点根目录与改过名的后台目录。

2. 上传程序到站点根目录

把发行包解压到站点根目录（虚拟主机的 public_html、VPS 的 /var/www/site、本机 XAMPP 的 C:\xampp\htdocs\qscms 都行）。程序不依赖特定路径，整站拷走即可迁移。

3. 访问站点，安装向导自动启动

浏览器打开站点域名即可。程序检测到没有安装锁文件时会自动跳到安装向导；反过来，想重装就把那把锁删掉再访问。

步骤做什么
1 账号验证填写站点账号（邮箱 + 授权码 SN），也可进入手动模式；校验请求只在提交表单时发出
2 环境检测检查 PHP 版本、扩展、压缩能力、配置目录可写性；缺什么按提示补
3 初始化数据选择云端恢复已有配置，或手动填写站点名称、描述、地址、后台账号与密码
4 完成写入安装锁，并提示删除 install 目录、修改后台目录名

4. 装完三件事（不做会留隐患）

  1. 删除或改名整个 install 目录——留着等于把安装入口挂公网。
  2. 改后台目录名——换成 6～10 位无规律名称，然后访问一次「新目录/set.php」，程序会自动记住；不用改代码、不用改配置。扫描器字典里的 /admin/ 从此全部落空，连登录页都摸不到。
  3. 核对基础设置——站点地址、主题、友链、时区与语言，用安装时的管理员账号登录后台逐项过一遍。

5. 伪静态：内页 404 一般都是这里

路由是把路径塞进 query string，所以 Nginx 必须用 rewrite 形式，只写 try_files 回退是不够的：

location / { try_files $uri $uri/ @qscms; }
location @qscms { rewrite ^/(.*)$ /index.php?$1 last; }
location ~ \.php$ {
    include fastcgi_params;
    fastcgi_pass unix:/run/php/php8.2-fpm.sock;
    fastcgi_param SCRIPT_FILENAME $document_root$fastcgi_script_name;
}

Apache 只需加载 rewrite_module、站点目录 AllowOverride All，改写规则由自带的 .htaccess 负责。

6. 发第一篇文章，再一键静态化

  1. 后台「文章 → 新建」，填标题、标签、日期，编辑器写正文（可插图库图片），保存为发布或草稿。
  2. 前台点开文章确认渲染正常，主题样式在「基本参数」里一键切换。
  3. 后台「静态化」：配置输出路径与站点地址 → 保存 → 生成，检查输出目录里的首页文件。
  4. 要把静态站放上 CDN 或 GitHub Pages，用静态站部署 / GitHub 同步功能推送，可全量也可增量。

7. 几个高频卡点

现象怎么处理
所有内页 404mod_rewrite 没开，或 AllowOverride 不是 All；Nginx 缺 rewrite 规则
打开首页跳安装页安装锁文件缺失，重新走一遍安装或手工补上锁文件
500 / 白屏主配置文件损坏或不可读；临时开 display_errors 看具体报错
图片上传失败上传目录不可写、后缀被扩展名策略拦截、PHP 上传上限太小
静态站空或缺页静态路径写错、静态主题不存在、生成缓存与源不一致；删缓存后全量重生成
